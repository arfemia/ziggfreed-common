# effect/control/ - the family's crowd control (R740)

- `StunControl` (stun, stagger, wake, the `Immune` and `Immunity` ramp) and `AggroControl` (taunt, drop, suppress), with the `ZigStun`, `ZigTaunt`, `ZigAggroDrop` and `ZigAggroSuppress` Types. A control that shrinks on repeat reads `immunityShare` before its landing ramps the stat and lasts `diminished` by it (`seconds * (1 - share)`), the one formula zc-track's proc `Control`, `ZigStun`'s `Diminish` (off unless written, so a consumer's stun keeps its length) and the MMO's controls share.
- Immunity to stuns is `StunControl.isImmune`, the one read every stun asks: the game's `Immune` effect, or an effect tagged `ZigStunImmune` (a boss only its fight may stun; no look of its own; `Zig_Stun_Immune` is the library's). A fight's own stun writes past it (`ZigStun`'s `IgnoreImmune`, or `StunControl.stun` called directly, as `ZigStunTarget` does); never a second immunity check elsewhere. The game's own stuns never ask, so the tag's values name the effects a wearer sheds (`Stun`, `Root`) and `StunImmunitySystem` takes them off the tick they land, before the tick's effect changes go out (`StunImmunity` reads the table off the effect files); only the ids named, never their children, so the library's own stun effects stay.
- A stun is the native `Zig_Stunned` or `Zig_Staggered` effect (`Parent: Stun`) and nothing else is kept: query and wake read the effect. A caller whose stun must keep its exact length (no family read, so no carrier's control resistance, reaches it) stuns with an effect of its own through `StunControl.stun(..., effectId)`, the same hold under that effect, and reads and ends that effect itself.
- An aggro window lives in the world's `AggroWindows` resource, never on the source entity; its attitudes go through the world's `AttitudeView` provider (`AggroAttitudes`), never a write into a creature's override memory, and `AggroSweepSystem` only edits fields of components a creature already has.
- `CreatureHold` is the one way a grab or a drive moves a creature (a per-tick `Set` velocity instruction toward a point, never the zero vector, never a raw component write) and `CreatureHold.canMove` the one rule for whom it may take: never a player, a `Zig_Boss_Or_Elite` creature, one wearing `Immune`, one whose role's `KnockbackScale` is 0, or one taller than the caller's cap.
- `AggroControl.tauntOne` pins one creature onto one taunter (zc-track's proc `Taunt`), kept beside the windows in the same resource and swept with them, ahead of any window's taunt on that creature; a creature takes a pin only as it takes an area taunt (its own attitude hostile or neutral, recorded on the pin, which alone makes the provider answer hostile), a pin ends with its time or its taunter (dead or gone), and when it ends the creature's default target slot is cleared only if it still holds the taunter. Never a second taunt mechanism elsewhere. `AggroControl.tauntedBy` is the one read of "a creature this taunter holds": a pin it took, or its target slot on the taunter while their area taunt is open.
