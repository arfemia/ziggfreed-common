# effect/control/ - the family's crowd control (R740)

- `StunControl` (stun, stagger, wake, the `Immune` and `Immunity` ramp) and `AggroControl` (taunt, drop, suppress), with the `ZigStun`, `ZigTaunt`, `ZigAggroDrop` and `ZigAggroSuppress` Types.
- A stun is the native `Zig_Stunned` or `Zig_Staggered` effect (`Parent: Stun`) and nothing else is kept: query and wake read the effect. A caller whose stun must keep its exact length (no family read, so no carrier's control resistance, reaches it) stuns with an effect of its own through `StunControl.stun(..., effectId)`, the same hold under that effect, and reads and ends that effect itself.
- An aggro window lives in the world's `AggroWindows` resource, never on the source entity; its attitudes go through the world's `AttitudeView` provider (`AggroAttitudes`), never a write into a creature's override memory, and `AggroSweepSystem` only edits fields of components a creature already has.
- `AggroControl.tauntOne` pins one creature onto one taunter (zc-track's proc `Taunt`), kept beside the windows in the same resource and swept with them, ahead of any window's taunt on that creature; a creature takes a pin only as it takes an area taunt (its own attitude hostile or neutral, recorded on the pin, which alone makes the provider answer hostile), a pin ends with its time or its taunter (dead or gone), and when it ends the creature's default target slot is cleared only if it still holds the taunter. Never a second taunt mechanism elsewhere. `AggroControl.tauntedBy` is the one read of "a creature this taunter holds": a pin it took, or its target slot on the taunter while their area taunt is open.
