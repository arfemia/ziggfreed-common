# zc-effects

- zc-effects and zc-loot never import each other: a reward that grants an effect is the `Effect` reward kind the wiring root registers (`reward/EffectRewardKind`).
- `NativeEffectUtil.has` answers false whenever it cannot tell, so a caller reconciling a wanted effect applies on false; `remaining` answers null for the same, read as not on. `applyInfinite` is the no-expiry overload for an entity with no `EntityStatMap` (a puppet or prop, where the engine's effect timer never runs): pair it with `remove`.
- An unresolved effect id is named at WARN once per id per process (`warnUnresolvedOnce`, from `apply` / `applyFor` / `remove`) and at FINE after that, so a caller reconciling on every change never repeats the line.
- `AppliedEffectTracker.removeAll` clears unconditionally, and a round or encounter `stop()` relies on that.
- `effect/costume/` is the costume a player can always take off. A costume is an effect that changes the model and is not a `Debuff` (`CostumeRules`); `ZigCostume` puts one on the player a chain targets and tells them `/zigcostume off` takes it off, and taking off goes by that rule, never by a record. A different costume is refused while one is worn: the engine keeps the model from before the first model change to restore, and a swap inside one tick would record the first costume's model instead. zc-cast is this module's one other library edge, for that Type.
- `effect/buff/` is the timed-buff binding. A consumer registers a `TimedBuffSource` once at setup (`TimedBuffs.register`) and calls `TimedBuffs.refresh(ref)` or `refreshAllOnline()` whenever its buffs change; the library refreshes on its own at every player-ready and respawn. A source answers per player (key, effect id or null, scope, ends-at) and never applies an effect itself; with no source nothing happens. The saved `BuffSlotsComponent` is registered unconditionally at setup, never behind whether a source exists.
- A buff naming no effect takes a slot of its scope's pool, `Zig_Buff_Personal` or `Zig_Buff_Server`: four slots each (`_2` to `_4` naming the base as `Parent`, seated by zc-core's `SlotPlan`), a fifth key of one scope sharing slot 4. The defaults ship Duration 1800, not Infinite, so the ring reads the remaining time against 1800 s; a pack restyles a pool by a same-id base file.
- A tile is applied with the buff's remaining time and `OVERWRITE` only when it is missing or drifts more than 5 s from its buff (`BuffPlan.DRIFT_SECONDS`), so its start never replays; nothing goes on a dead player.
- The eight `Zig_Buff_*` ids, and any effect a source names, belong to the binding: it takes off every one no live buff wants, so a pack never applies them itself.
- `effect/grid/` carries a per-entity number through a native effect field that only reads assets (`DamageResistance`, `OutgoingDamage`): a `RuntimeEffectGrid` writes one shared asset per bucket the first time anyone needs it, through `AssetStoreWriter`, never one per entity (each joins the catalogue every client syncs), so pick a bucket rule whose count stays bounded. A grid owns every active effect under its prefix (`reconcile` sweeps the unwanted ones); an apply inside a tick can answer `PENDING` and re-runs from `onLanded` (wrap with `onWorldThread`). `EffectBodies.rootCauses` is the key set for an `OutgoingDamage` body, which matches a hit's whole Inherits chain.
