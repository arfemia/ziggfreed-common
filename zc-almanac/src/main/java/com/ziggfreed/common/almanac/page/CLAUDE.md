# almanac/page/

- The page paints and delegates: what a season shows is decided in `view/AlmanacView` (records) and what it says in `view/AlmanacLines` (which countdown line, the dates line); `AlmanacPagePlan` maps them to the kit's records, and `AlmanacPage` only paints a plan through the kit. Each part of the body is a template appended into `#Sections` in the order the season's `Sections` writes it (`Pages/ZigAlmanac<Part>.ui`), addressed `#Sections[i] #Id`; `AlmanacPageDocumentTest` resolves each such selector inside the template appended at `i`. A part's button binds `Action` `section` with its index, answered from the plan the last build painted. `AlmanacPagePlanTest` holds the plan, and `AlmanacPageDocumentTest` drives the paint against the documents, so every id the page sets exists (a missing one drops the player).
- A season page's `Hero` is a shipped `Art` (shown while `ShowArt`) or a `Composition` of item pictures on the 962 x 240 plate. Nothing clips a child to the hero plate: every layer the page places stays inside 962 x 240.
- A season page's `Sections` lays out its body in the order written, one part per entry (`Banner`, `Collection`, `Achievements`, `Tallies`, `Keepsakes`, `Links`; an entry naming two draws the first); with no `Sections` the page reads Tallies, Keepsakes, Achievements, Links. A section's `Button` is a link (a storefront is `{ "Type": "Shop", "Shop": <id> }`).
- The menu tab's two knobs are `$MenuTab.Show` and `$MenuTab.OnlyWhileLive` in `mods/ziggfreedcommon/almanac.json` (`asset/AlmanacOwnerLayers` reads and writes them), and `AlmanacPages.menuTabVisible` is the one rule a tab or a consumer's tile asks. `AlmanacPages.headline` names every season on now (one, two, or the first and how many more); the MMO hub tile shows it, the menu tab does not. The menu tab's second line (`AlmanacMenuTab.subline`) names the live event that started last (`liveAll`, ordered by `Occurrence.IN_ORDER`, never by id or number) among those whose calendar file has both a title key and an icon (`titleKey`, `icon`), else the season on now by its Almanac page.
