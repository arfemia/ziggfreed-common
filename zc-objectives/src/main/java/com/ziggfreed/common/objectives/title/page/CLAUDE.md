# objectives/title/page/ - the title picker

- The picker opens only through `TitlePickerPages.open` (the `Titles` destination, `TitleDestinations`, registered by `TitleBootstrap`, opens it too, and so does `/zigtitle open`). What it lists is the pure plan `TitlePickerRows`: earned titles as tiles (`Pages/ZigTitleTile.ui`, on the Memories tile faces) under an "n of N" head, and the titles still to earn that are not hidden as kit lines.
- A line names the first visible achievement, else the first visible quest (list order, then id), that grants its title (`TitleSources`, `Source.kind`) and opens the book on it, or says to collect it when a visible granter holds the title for a collect it waits on (an achievement paying it only on collect, earned and not collected; a quest parked in `COMPLETED_UNCLAIMED`, which holds every reward) (`Source.collect`; such a granter wins over an earlier one, an achievement's over a quest's: `TitleSources.first`). A quest line pictures the quest's own icon, else none. A hidden achievement is never named, a quest only while `QuestEngine.isVisible` lists it (a started one always), and neither kind while its system is switched off for the player.
- With nothing earned and only hidden titles left, the empty state reads `picker.secret_only`; `none_on_server` is for a server with no title on offer. While `$Chat` is on, the subtitle reads `picker.subtitle_chat`.
- A consumer themes it through `TitlePickerPages.deps`; Back returns to the Settings tab unless the consumer says otherwise, and an open given a Back destination (`open(..., back)`, `TitleDestinations.titles(back)`, a Java-only field no file can author) goes there instead.
- `TitlePickerDocumentTest` holds every id the page addresses.
