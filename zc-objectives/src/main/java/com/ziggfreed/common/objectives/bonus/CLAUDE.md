# objectives/bonus/ - the library's bonus rows on the produced moments

- `BonusRowReactions` is a `MomentListener` registered at library-default rank (`BonusRowBootstrap`). It reads only `loot/trigger/BonusRowConfig`, never a consumer's table, and decides with no world handle first (`rowFor`: the kind, the producer's own payload, a covering row that is not a hole).
- It pays through the moment's own quest subject, so a consumer's notification preferences reach a cue toast; a `PlayerRefSubjectHandle` subject stands in when the runtime built none.
- Its kill and break passes layer a `ChestSite` (`BonusMoment.libraryCarries`) and stand the first `Reward_Chest` file it collected through zc-instance's `SpoilsChests.stand`, at the corpse or the block, for the credited player alone, under a fresh `chest:<uuid>` key.
- A row reads the loot vocabulary the rolling kinds read (`LootRewardKinds.installedFactors()`), and its context carries the player, a kill's victim (`target`) and a harvest's stack (`item`). No consumer payload rides it, so a consumer factor that needs one answers nothing in a library row.
