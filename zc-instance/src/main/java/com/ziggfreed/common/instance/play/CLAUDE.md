# instance/play/ - the Public, Party and Solo play screen

- The title and the difficulty line are the band frame's hero (`ui/kit/HeroPainter`: the gold title, the copper tagline). Every Label (`#PlayerCount`, `#Status`, `#WaitEstimate`, a card's `#CardSub`) takes a consumer's line, perhaps parameterized, so it is painted on `.TextSpans`, never `.Text` (which prints `{0}`); the buttons (`#CardBtn`, the whole mode card, `#ClaimBtn`, `#LeaveBtn`) are `ZigRichButton`s, labelled through `ZigRichButton.text`, and a card's picture is the kit's plain picture slot (`IconRenderer.applyPlainIcon`), never an `ItemGrid`, whose tooltip would take the card's click.
- The live countdown push updates only the template scalars (`#Status`, `#PlayerCount`), never the appended roster rows, and checks `isDismissed()` on the world thread first (a push to a stale page crashes the client); it writes through `ToastablePage.writeInPlace`.
- Queue-mode content (which modes, their icons, order and labels) lives in the consumer's `Server/ZiggfreedCommon/Instances/*.json` `QueueModes` block; `QueueModeSet.fallback()` is a structural net, never content.
