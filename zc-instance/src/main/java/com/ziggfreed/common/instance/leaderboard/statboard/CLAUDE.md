# instance/leaderboard/statboard/

- The stat board ranks every player's stats (`mods/ziggfreedcommon/stats-board.json`, a `Leaderboard` on a 10-second debounce, compact JSON); it is a rank index, never the record. The store that keeps the stats (above this module, which never sees it) writes through `StatBoard.add`, `raise` and `lower` (`all_time` plus every running window) and `setAllTime` (gauges, native reads, the re-sync at ready), and fills `StatBoardSource` (on or off, a line's column) through `StatBoard.setSource`. A one-time import (an old board's rows) runs through `StatBoard.importOnce`, claimed in the board's `imports` and written through `setAllTime`, so a restart never imports twice. Unfilled, the board knows no column, shows nothing, and Records stays the encounter board.
- A bucket is `all_time`, `<period id>@<window>` for a week or a month (`weekly@2026-W42`, `monthly@2026-10`), or `range@<id>`. A new window's key is the reset: nothing clears a bucket, and a turnover keeps the period's newest `Keep` windows (`Leaderboard.retain`, run after the write so the running window counts). `PeriodWindows` keys sort as text in time order, which retain relies on.
- Only a line some `StatSections` file names is written (`StatSectionConfig.ranked`). A line the source gives no column shows none, and a section left with none shows no tab, so a zc-only server shows no column nobody counts (M513).
- Periods are `Server/ZiggfreedCommon/StatPeriods/`; a server owner's overrides and ranges are the top-level entries of `mods/ziggfreedcommon/stats.json` (`StatPeriodOwnerLayers`), whose `$` keys (`$Enabled`) are the store's.
- Records opens this board first (`RecordsDestinations.setBoard`, filled by `InstanceBootstrap.installStatBoard`): sections over periods, each section with its own columns, the Stats view alone and no All tab (`LeaderboardPageDeps.withColumnsByPrimary`, `withoutAllTabs`, `statsOnly`).
- A long span of seconds (playtime) takes `ColumnFormat.DURATION`, worded "12h 30m" by `StatBoardMessages.duration` on the cell's `TextSpans`; `TIME` (m:ss) is for a short one, such as a fight's best time.
- `StatClock` is the board's time. `/zigleaderboard clock <offset>` moves it in memory only, to smoke a turnover; while the offset is not zero, a write lands in `all_time` alone and nothing is pruned (`StatBoard.writeWindows`, one read of the offset per write), so a trial never leaves a future window behind for `retain` to keep over the real one. The board's words are `ziggfreedcommon.statboard.lang`.
