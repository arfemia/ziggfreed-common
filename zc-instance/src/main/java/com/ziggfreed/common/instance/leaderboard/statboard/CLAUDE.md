# instance/leaderboard/statboard/

- The stat board ranks every player's stats (`mods/ziggfreedcommon/stats-board.json`, a `Leaderboard` on a 10-second debounce, compact JSON); it is a rank index, never the record. The store that keeps the stats (above this module, which never sees it) writes through `StatBoard.add`, `raise` and `lower` (`all_time` plus every running window) and `setAllTime` (gauges, native reads, the re-sync at ready), and fills `StatBoardSource` (on or off, a line's column) through `StatBoard.setSource`. A one-time import (an old board's rows) runs through `StatBoard.importOnce`, claimed in the board's `imports` and written through `setAllTime`, so a restart never imports twice. Unfilled, the board knows no column, shows nothing, and Records shows no tab.
- A bucket is `all_time`, `<period id>@<window>` for a week or a month (`weekly@2026-W42`, `monthly@2026-10`), `<period id>@<event>:<run>` for a SeasonRun (`season@hallows_eve:2026`, `2026#09` for a year's run 9, the number padded), or `range@<id>`. A new window's key is the reset: nothing clears a bucket, and a turnover keeps the period's newest `Keep` windows, of a season per event (`Leaderboard.retain`, run after the write so the running window counts). `PeriodWindows` keys sort as text in time order, which retain relies on; a bucket key never carries `|`.
- A SeasonRun's keys sort in time order only while an event's run numbers follow its dates (a yearly, monthly or weekly event, spans listed in date order); retain drops the lowest key, so a span list out of date order can drop the wrong run.
- A SeasonRun reads zc-core's `Occurrences` on the board's clock: its `Event` (`*` for every live event) writes each live run's bucket (a write asks `Occurrences.liveAllCached`, once a second), and Records shows a tab per live run and per run the board still holds of an event the server loads, keyed by the bucket itself. A season tab is a `LeaderboardBucketTab.withSpans` (a kit segment, its label on `.TextSpans`), named by its `NameKey` with the event's title as a translation and the year, so each player reads it in their own language; a run's number never reaches a player. The store's `Seasons` bag is the store's, never the board's.
- Only a line some section names is written (`StatSectionConfig.ranked`): a `StatSections` file, or a section the store generates in code (`StatSectionConfig.generated`, an owner's whole set; a file of the same id wins), such as a season page's `season_<event>`; `authored()` is the files' alone, for the audit. A tab's `NameKey` resolves through `ContentKeys.resolved`, so a pack's short key names it; a generated section naming none takes its `event`'s title from `Occurrences` as each page builds (`StatBoardRecords.sectionNameKey`), never at generation, since the calendar may load its events later. A line the source gives no column shows none, and a section left with none shows no tab, so a zc-only server shows no column nobody counts (M513).
- A `Stat/*` line (`StatSection.everyLineOf`) names every line of that stat, never its total: each is ranked. On the sections row it shows one column per line the source lists now (`StatBoardSource.everyLine`, a native stat's reader's things, such as each reputation), within the section's four; a counted stat lists none. The `boss_fights` section's are Records' Boss Fights (`StatBoardBossFights`) instead: one column per `Stat/*` stat, a fight per tab (a key some player holds in `all_time`, named by its binding row through `EncounterBoards.fightTabs`; a split fight's tab is a `withSpans` one), each read on that fight's line through the source, the sections' period row (`StatBoardRecords.periodTabs`) under them.
- A section's tab splits in code (`StatSectionConfig.split(sectionId, StatSplit)`, by whoever owns the lines, at setup): stats with a line per thing, each a column with its own label and a floor a line must pass to count toward a group's sum; groups and their things from a supplier asked as each page builds; a viewer filter. Every line of a split stat is ranked, as a `Stat/*` line's are. `StatBoardRecords.split` turns it into the page's `LeaderboardSplit`: a group sums its things' lines (`<Stat>+<group>` keys, never stored), a thing reads its own, a line the source gives no column is left out, and a split whose stats all hold all-time numbers alone (`StatBoardSource.allTimeOnly`: a gauge, a native reading) pins its choices to the All Time period. Nothing registered means no split, so a zc-only server's tabs have none.
- As Records opens, the filled board refreshes the opener first (`RecordsBoard.opening`, `StatBoard.refresh`, `StatBoardSource.refresh`): the store sets their native readings, so their own numbers stand as of now; anyone else's stand as of their last login or open.
- Periods are `Server/ZiggfreedCommon/StatPeriods/`; a server owner's overrides and ranges are the top-level entries of `mods/ziggfreedcommon/stats.json` (`StatPeriodOwnerLayers`), whose `$` keys (`$Enabled`) are the store's.
- Records opens this board first (`RecordsDestinations.setBoard`, filled by `InstanceBootstrap.installStatBoard`): sections over periods, each section with its own columns, the Stats view alone and no All tab (`LeaderboardPageDeps.withColumnsByPrimary`, `withoutAllTabs`, `statsOnly`). A section file's `Icon` pictures its tab (a generated section takes its event's icon, anything else `StatBoardRecords.PICTURE`) and its `HintKey` is the line on how to get on its board (else the board's `hint`); the `boss_fights` file's pair serves every fight's tab and Records' Boss Fights tab.
- A long span of seconds (playtime) takes `ColumnFormat.DURATION`, worded "12h 30m" by `StatBoardMessages.duration` on the cell's `TextSpans`; `TIME` (m:ss) is for a short one, such as a fight's best time.
- `StatClock` is the board's time. `/zigleaderboard clock <offset>` moves it in memory only, to smoke a turnover; while the offset is not zero, a write lands in `all_time` alone and nothing is pruned (`StatBoard.writeWindows`, one read of the offset per write), so a trial never leaves a future window behind for `retain` to keep over the real one. The board's words are `ziggfreedcommon.statboard.lang`.
