# world/placed/ - the placed-block ledger

- A consumer only reads `PlacedBlockLedger`; the library's `PlacedBlockRecorder` is the one writer of player placements. A second recorder over-counts placed items once per installed mod. The one other writer is the library's `world/temp/TempBlocks`, which marks the cell of a temporary block it put down with an empty hand (a placement the recorder never sees) as placed and spared, and spends both marks when the block crumbles.
- Ask `PlacedBlockRecorder.placementCounts` whether a placement counts; never re-implement its filters (cancelled, empty hand, creative mode, `world/BuildPermission`).
- Two questions, never mixed (R879). Who placed a block is one answer, recorded for every real placement whatever the policy (exempt and creative builders included): `placedBy` (the game's own `PlacedByInteractionComponent` where the block has a block entity, the section's `PlacerPalette` elsewhere, a spent mark inside the grace window), `wasPlaced` its yes or no, `isPlacedBy` for one player, and the static `placerAt` for a chunk-store system already holding the refs. A rule about who built a block (a shape's `Placed` and `Own`, `GatherSpeed_Placed`, growth's planter) reads these and never the credit reads. Credit is `isPlaced` and `consumePlacement`: a placement the guard holds (the policy on, the placer neither exempt nor in creative), which is all XP, progress and loot ask.
- `consumePlacement` spends the block's record at break time whatever the policy, and every reader of the same break inside the grace window hears the same credit answer and placer; `isPlaced` only observes. An item read passes a `momentKey` stable for the one event, so several readers of it spend one copy.
- Exempt a builder through `Policy.guardsPlacementsBy`, which records the placement outside the guard, never by softening the read: nobody earns from a guarded placement, whoever breaks it.
- With no world resolved, treat a block as not placed; never pass a null world.
- The palette keeps a (placer, guarded) pair per entry: one entry a section one player built in, a packed index a block once a second arrives; an entry saved before the guard state was kept reads guarded.
- The spared mark (`markSpared`, `isSpared`, `clearSpared`) marks a placement the library's thrift step kept the item of, so its break drops nothing, and keeps the spared block's own item id (`sparedIdentity`, shared by its states and rotations). Only `gather/ThriftSystem` and `world/temp/TempBlocks` set it; any other player placement on the cell and every break with no breaker (`gather/ThriftDropSystem.EnvironmentBreak`) clear it, and `isSpared` takes the block now in the cell and forgets a mark naming another one (physics and a mod's direct write fire nothing). The saved form's flag bit 2 stays reserved (a build that never shipped wrote bare spared bits there).
