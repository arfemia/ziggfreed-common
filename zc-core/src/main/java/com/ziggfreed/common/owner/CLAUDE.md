# owner/ - who administers the server, and which owner files an editor may write

- `OwnerAudience` is the one "may this player change the server's settings" answer: a consumer fills it once at setup, else a player holding `OwnerAudience.NODE` (`/zigadmin`'s engine node) is an owner. Every owner screen asks it on open and on every event, and each library owner page's own audience seam defaults to it.
- `ServerOperators` is the one "is this player an operator" answer: the game's own operator group (`HytalePermissionsProvider.GROUP_ADMIN`, read through `PermissionsModule.getGroupsForUser`, as `/op self` reads it), never a permission node, fail-closed. It keeps to the operators what reaches past the settings (a console command an owner writes); a form field asks it through the portable factor `hytale:operator` (zc-entity's `HytaleFactors`), a code page calls it directly. Never ask `hasPermission("OP")` or `*` for it.
- An editor writes an owner file only through its `OwnerFileBinding`, registered in `OwnerFileBindings` by the mod that reads the file: the binding owns the path, the Default reading, the writer and the reload, so a form's text never builds a path. A keyed store binds with one `OwnerFileBinding.keyedStore` line, which also carries its `Entries` (ids in force, the layer under the owner, each entry encoded, the store's own entry writer) for an editor that writes one entry at a time; a consumer's own file type passes its own `Below` and `Writer`. A file whose shape a form's dotted paths cannot address (a leaf inside a list, a map that stands whole) names a `View` (the owner's file as an editor reads it) beside an `Entries` writer that turns those paths back into the file's shape (zc-track's curves and world rules).
- A file's `$` keys are never an editor's, but ONE the binding declares (`Builder.reserved`, almanac.json's `$MenuTab`, track-world-rules.json's `$Enabled`): a form writes it by its own path (`$MenuTab.Show`), and `write` refuses, writing nothing, any leaf naming another `$` key. Never a second reserved key on one binding.
