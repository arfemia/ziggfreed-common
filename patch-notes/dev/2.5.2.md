CommonLib 2.5.2 is a data hotfix cut from 2.5.1: the quest-giver role template serves several players at once. No API changes.

## Changed

- `Template_Zig_QuestGiver` (zc-dialogue, `Server/NPC/Roles/Passive/`): no `BusyStates`, so the engine's `willInteractWith` no longer refuses every other player while the giver sits in `$Interaction`; the press-F instruction runs on every `HasInteracted` (its `Not State $Interaction` guard is gone), so each press opens that player's page, turns the head to the newest player and restarts the one-second look; `CanInteract` has no `ViewSector`, so a player in reach presses F from any side, not only the half the head faces. A Variant built on the template needs no change. A consumer's own full role body copied from the template keeps the old limit until it takes the same three edits.
