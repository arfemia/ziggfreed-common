CommonLib 2.4.1 is a hotfix on 2.4.0 that lets the Asset Editor open again on a server running it. Built for Update 7, like 2.4.0, and nothing built against 2.4.0 needs a change.

## Fixes

- Fixed a crash that stopped the Asset Editor from opening on a server running CommonLib 2.4.0. When the editor starts, it asks every NPC action what fields it takes, and three of the library's actions could not answer, so the editor never finished loading. All three answer now, and the editor lists their fields.
